# クムドールの試練

`kumdor_01.c` は、ターミナルで遊ぶタイピングRPGの試作版です。

表示されたアルファベットを入力して敵を攻撃します。敵のHPを0にすれば勝利、プレイヤーのHPが0になると敗北です。

## 現在の内容

- C言語製のターミナルゲーム
- プレイヤーと敵を `struct` で管理
- ターン制バトル
- プレイヤーHPと敵HP
- 敵の反撃
- 毒と暗闇の状態異常
- 大文字・小文字どちらの入力にも対応

## 必要な環境

- Cコンパイラ
- `make`

macOSでは、Command Line Tools が入っていればビルドできます。

## ビルド

```sh
make
```

以下の実行ファイルが作成されます。

```text
kumdor_01
```

## 実行

```sh
make run
```

または、直接実行できます。

```sh
./kumdor_01
```

## クリーンアップ

```sh
make clean
```

生成された実行ファイルや一時的なビルド成果物を削除します。

## GitHub公開の目安

最初の公開は、単語入力、複数の敵、簡単なステージ制が入り、READMEの手順通りにビルドして遊べる状態になってからを目安にします。

最低限、公開前に確認すること:

- `make` で警告なしにビルドできる
- `make run` でゲームを開始できる
- 勝利と敗北の両方が自然に発生する
- READMEに遊び方とビルド方法が書かれている
- 実行ファイルなどの生成物がGit管理に入っていない
- ライセンスを追加している

現在の状態でも開発ログとして公開できますが、公開ゲームとして見せるなら「ステージ1からボス撃破まで一通り遊べる」状態を最初の目標にします。
