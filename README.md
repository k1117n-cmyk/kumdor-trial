# クムドールの試練

Version: `v0.5.1`

C言語製のターミナルタイピングRPGです。

紹介記事:
https://pc-fan.net/kumdor-trial-c-terminal-typing-rpg/

表示された課題をそのまま正確に入力して敵を攻撃します。プロローグから始まり、クムドール王国をめぐる10個のステージで敵を順番に倒せば完全勝利、途中でプレイヤーのHPが0になると敗北です。

ステージごとに練習内容が変わります。最初はホームポジションの `f` / `j` / スペースから始まり、ホーム段、上段、下段、数字、Shift記号へ段階的に進みます。
各ステージでは単キーだけでなく、左右交互、短い単語、スペース入りの課題も出題されます。
ステージ開始時には、そのステージで主に意識するキーを「今回のキー」として短く表示します。

## すぐに遊ぶ

```sh
git clone https://github.com/k1117n-cmyk/kumdor-trial.git
cd kumdor-trial
make
make run
```

更新内容は [CHANGELOG.md](CHANGELOG.md) にまとめています。

## 必要な環境

- Cコンパイラ
- `make`

macOSでは、Command Line Tools が入っていればビルドできます。
ステージ別BGMはmacOS標準のAVFoundationを使ってループ再生します。

## ビルド

```sh
make
```

以下の実行ファイルが作成されます。

```text
kumdor_01
```

## 実行

```sh
make run
```

または、直接実行できます。

```sh
./kumdor_01
```

タイトル、ステージ見出し、戦闘ログ、セーブ、スコアなどはANSIカラーで表示されます。
色を出したくない場合は、`NO_COLOR=1` を付けて実行できます。

```sh
NO_COLOR=1 ./kumdor_01
```

macOSでは、`BGM/kumdor_01.wav` のようなステージ番号付きファイルがある場合、ステージ開始時にBGMを再生します。
対応するBGMファイルがないステージは無音で続行します。
BGM再生を開始できない場合もゲームは止めず、そのステージは無音で続行します。
BGMの音量は `KUMDOR_BGM_VOLUME` で `0.0` から `1.0` の範囲で指定できます。
指定がない場合や不正な値の場合は、既定値の `0.45` で再生します。
BGM開始時の `[音]` ログには、実際に使われる音量が表示されます。
BGMを鳴らしたくない場合は、`KUMDOR_NO_BGM=1` を付けて実行できます。
ゲーム中は入力欄で `:bgm` または `:mute` と打つとBGMのON/OFFを切り替えられます。
`KUMDOR_NO_BGM=1` で起動した場合は、ゲーム中のBGM切り替えも無効です。

```sh
KUMDOR_BGM_VOLUME=0.3 ./kumdor_01
KUMDOR_NO_BGM=1 ./kumdor_01
```

セーブデータがある場合は、起動時にロードするか確認されます。

```text
記録の石板が見つかりました。
前回の続きから始めますか？ (y/n):
```

セーブデータは `kumdor_save.txt` に保存されます。このファイルはGit管理しません。
セーブデータには `KUMDOR_SAVE_V3` の形式識別子を入れており、読み取れないデータや不正な値がある場合は新しく始めます。
古い `KUMDOR_SAVE_V1` / `KUMDOR_SAVE_V2` のセーブデータも読み込めます。
ステージ別成績は現在のプレイ中に集計され、ステージ突破時とゲーム終了時に表示されます。`KUMDOR_SAVE_V3` ではステージ別の正解数、ミス数、入力失敗数、最大連続正解数を保存します。
毒と暗闇は一時的な状態異常のため、セーブデータには持ち越しません。

ゲーム中に中断したい場合は、入力欄でコマンドを入力できます。

| コマンド | 内容 |
| --- | --- |
| `:help` | ヘルプを表示 |
| `:commands` | ヘルプを表示 |
| `:?` | ヘルプを表示 |
| `:bgm` | BGMのON/OFFを切り替え |
| `:mute` | BGMのON/OFFを切り替え |
| `:save` | 現在ステージの入口に記録を刻む |
| `:quit` | 記録を刻まずに終了 |
| `:savequit` | 記録を刻んで終了 |

中断セーブでは敵HPの途中状態は保存せず、現在ステージの先頭から再開します。

敵には反撃特性があります。戦闘開始時に特性名と説明が表示されます。
毒状態では、正解しても攻撃できず毒の解除に使われます。毒中に失敗が続くと追加ダメージを受けます。
暗闇状態では、課題の一部と入力中の文字が画面に表示されません。正解すると暗闇は解除されます。
ステージ3以降は、タイプミス時の共通ペナルティとして一時的に暗闇状態になります。
3連続正解するたびに追加の一撃が入り、敵にもう1ダメージを与えます。
敵が本気を出した後は、反撃の予兆が表示されるターンがあります。予告が出たターンにミスすると、強打、毒刃、暗闇、再生などの反撃特性が発動します。
ミス時には、入力が短い、長い、先頭が違う、途中が違うといった短いフィードバックが表示されます。

| 特性 | 内容 |
| --- | --- |
| 標準 | 特別な追加効果はありません |
| 強打 | 敵が本気を出した後、予告が出たターンの反撃ダメージが1増えます |
| 毒刃 | 反撃時と敵が本気を出した後に毒を付与し、失敗が続くと追加ダメージを与えます |
| 暗闇 | 反撃時と敵が本気を出した後に一時的な暗闇を付与し、課題の一部を見えにくくします |
| 再生 | 敵が本気を出した後の反撃時に敵HPが1回復します |

ステージ突破後は自動セーブされ、次のステージへ進む前に確認が表示されます。
ステージ突破時には、命中率やミス数に応じた短い突破評価も表示されます。

```text
次の試練へ進みますか？ 第3/10ステージ
Enter: 進む / q: ここで剣を収める（記録済み）:
```

ここで `Enter` を押すと次のステージへ進み、`q` を入力すると記録を使って次回そのステージの入口から再開できる状態で終了します。

## ステージ構成

| ステージ | 場所 | 練習内容 |
| --- | --- | --- |
| 1 | アズドフ村の墜落跡 | ホームポジション: `f` / `j` / スペースの連続入力 |
| 2 | アズドフ東の石畳 | 左手ホーム段: `a s d f` の単語・スペース入り課題 |
| 3 | ジュクルン村の鐘楼 | 右手ホーム段: `j k l ;` の単語・セミコロン混在 |
| 4 | ミルファ湖の沈んだ桟橋 | 人差し指の上段: `r t y u` の短い単語 |
| 5 | クムの森の入口 | 上段の広がり: `q w e i o p` の単語・複合課題 |
| 6 | ズロワノフ通路跡 | 中央から下段: `g h v b n m` の長めの単語 |
| 7 | ケムリ苔の水晶洞 | 下段と記号: `z x c , . / ?` の連続入力 |
| 8 | 王立図書庫の地下 | 総合練習: 大文字・小文字・記号・短い複合語 |
| 9 | クミエル通信塔 | 数字キーと記号: 数字列、`-`、`/`、`%`、`:` |
| 10 | 通信塔最上階 | 最終練習: Shift記号、大文字、数字、スペース混合課題 |

## バランス方針

序盤は基本キーを覚えながらも、連続入力や短い単語で単調になりすぎないようにしています。中盤からはスペース入り課題や長めの単語が増え、後半は大文字小文字の切り替え、数字と記号の混在に集中する構成です。各ステージは基本10問で突破する長さにし、敵HPが半分以下になると敵が本気を出します。本気状態では通常課題の後半流用ではなく、専用の課題から出題します。これにより、5問前後のあいだ少し長めの課題や敵ごとの反撃特性を体感しやすくしています。3連続正解の追加ダメージでテンポを出し、本気状態中の予告行動でミス前の緊張感を作ります。後半の敵は攻撃力も少し高く、難しい課題に触れる回数が増えます。強打は予告が出たターンの反撃を重くし、再生は本気状態中の反撃で敵HPを戻します。敵の反撃はタイプミス時だけ発生し、ステージ突破、レベルアップ、3ステージごとの休憩イベントでHPを回復できます。休憩時には外部コマンドに依存せず、第3ステージ後にクムムースの助言、第6ステージ後に補給車クム3号、第9ステージ後に旅の札が短く表示されます。

## クリーンアップ

```sh
make clean
```

生成された実行ファイルや一時的なビルド成果物を削除します。

## 検証

ビルドできることを確認します。

```sh
make
```

セーブデータの互換ロードと不正データ時の扱いは、簡易チェックで確認できます。

```sh
make check-save
```

このチェックは一時ディレクトリで `KUMDOR_SAVE_V1` / `KUMDOR_SAVE_V2` / `KUMDOR_SAVE_V3` のロード、不明形式、クリア済みセーブ、V3保存を確認します。

## 既知の制限

- BGM再生はmacOSのみ対応しています。macOS以外でもゲーム本体はBGMなしで遊べます。
- BGMファイルがないステージは補助ログを出さず、無音で続行します。
- BGM再生開始に失敗したステージは、短い `[音]` ログを出して無音で続行します。
- セーブはステージ途中の敵HPや状態異常を保存せず、現在ステージの先頭から再開します。
- セーブファイル名は `kumdor_save.txt` 固定で、複数スロットには未対応です。
- 暗闇状態では入力内容を隠し、画面上の課題の一部を `?` で隠します。
- 休憩中の小イベントはゲーム内蔵の表示で、`cowsay` や `fortune` などの外部コマンドは不要です。
