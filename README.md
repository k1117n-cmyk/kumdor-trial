# クムドールの試練

Version: `v0.1.0`

C言語製のターミナルタイピングRPGです。

紹介記事:
https://pc-fan.net/kumdor-trial-c-terminal-typing-rpg/

表示された課題をそのまま正確に入力して敵を攻撃します。プロローグから始まり、クムドール王国をめぐる10個のステージで敵を順番に倒せば完全勝利、途中でプレイヤーのHPが0になると敗北です。

ステージごとに練習内容が変わります。最初はホームポジションの `f` / `j` / スペースから始まり、ホーム段、上段、下段、数字、Shift記号へ段階的に進みます。
各ステージでは単キーだけでなく、左右交互、短い単語、スペース入りの課題も出題されます。

## 必要な環境

- Cコンパイラ
- `make`

macOSでは、Command Line Tools が入っていればビルドできます。

## ビルド

```sh
make
```

以下の実行ファイルが作成されます。

```text
kumdor_01
```

## 実行

```sh
make run
```

または、直接実行できます。

```sh
./kumdor_01
```

セーブデータがある場合は、起動時にロードするか確認されます。

```text
セーブデータが見つかりました。ロードしますか？ (y/n):
```

セーブデータは `kumdor_save.txt` に保存されます。このファイルはGit管理しません。

ゲーム中に中断したい場合は、入力欄でコマンドを入力できます。

| コマンド | 内容 |
| --- | --- |
| `:save` | 現在のステージの先頭から再開できる状態で保存 |
| `:quit` | 保存せずに終了 |
| `:savequit` | 保存して終了 |

中断セーブでは敵HPの途中状態は保存せず、現在ステージの先頭から再開します。

ステージ突破後は自動セーブされ、次のステージへ進む前に確認が表示されます。

```text
次の試練へ進みますか？ 第3/10ステージ
Enter: 進む / q: ここで終了（セーブ済み）:
```

ここで `Enter` を押すと次のステージへ進み、`q` を入力するとセーブ済みの状態で終了します。

## ステージ構成

| ステージ | 場所 | 練習内容 |
| --- | --- | --- |
| 1 | アズドフ村の墜落跡 | ホームポジション: `f` / `j` / スペース |
| 2 | アズドフ東の石畳 | 左手ホーム段: `a s d f` |
| 3 | ジュクルン村の鐘楼 | 右手ホーム段: `j k l ;` |
| 4 | ミルファ湖の沈んだ桟橋 | 人差し指の上段: `r t y u` |
| 5 | クムの森の入口 | 上段の広がり: `q w e i o p` |
| 6 | ズロワノフ通路跡 | 中央から下段: `g h v b n m` |
| 7 | ケムリ苔の水晶洞 | 下段と記号: `z x c , . / ?` |
| 8 | 王立図書庫の地下 | 総合練習: 大文字・小文字・記号 |
| 9 | クミエル通信塔 | 数字キー: `1` から `0` |
| 10 | 通信塔最上階 | 最終練習: Shift記号と混合課題 |

## バランス方針

序盤はミスしても立て直しやすく、後半は長い課題や記号入力に集中できるようにしています。敵の反撃はタイプミス時だけ発生し、ステージ突破やレベルアップでHPを回復できます。
