# クムドールの試練

`kumdor_01.c` は、ターミナルで遊ぶタイピングRPGの試作版です。

表示されたアルファベットを入力して敵を攻撃します。敵のHPを0にすれば勝利、プレイヤーのHPが0になると敗北です。

## 現在の内容

- C言語製のターミナルゲーム
- プレイヤーと敵を `struct` で管理
- ターン制バトル
- プレイヤーHPと敵HP
- 敵の反撃
- 毒と暗闇の状態異常
- 大文字・小文字どちらの入力にも対応

## 必要な環境

- Cコンパイラ
- `make`

macOSでは、Command Line Tools が入っていればビルドできます。

## ビルド

```sh
make
```

以下の実行ファイルが作成されます。

```text
kumdor_01
```

## 実行

```sh
make run
```

または、直接実行できます。

```sh
./kumdor_01
```

## クリーンアップ

```sh
make clean
```

生成された実行ファイルや一時的なビルド成果物を削除します。
